Semantic Tags

Semantic tags are HTML elements that clearly describe their purpose and the content they contain to both the browser and the developer. Unlike generic tags like /div or span, which tell you nothing about the information inside, semantic tags provide a meaningful structure to a webpage.

Common Sementic Tags

  1. Contains introductory content or navigation links, often including a logo or title.
  2. Specifically used for a block of navigation links.
  3. Defines the primary, unique content of the document.
  4. Groups related content together into a thematic section.
  5. Encloses self-contained content that could be distributed independently, like a blog post or news story.
  6. Holds content that is indirectly related to the main text, often used for sidebars.
  7. Contains information about the page creator, copyright data, or contact links.
  8. Used to wrap an image (figure) and its descriptive caption together.
  9. : Represents a specific period in time or a date.
