8.What is the purpose of universal selector in CSS?

*The purpose of the universal selector in CSS, represented by an asterisk (*), is to target and apply styles to every single element on a web page. It acts as a wildcard that matches any element type within its specified scope.

14.What is the difference between px, em, rem, and percentage units?

1.em(element based):Is used for Component-specific sizing (e.g., padding inside a button that scales with its text size).

2.px is mainly used for Borders, shadows, exact spacing, or fixed-size images.

3.rem(root element):font size of root element or mainly typography and layout.

4.% :the size of parent element property .fluid layout dimension like width or height.
