Internal CSS

Internal CSS (also known as embedded CSS) is a method used to style a single HTML page by placing CSS rules directly within the HTML document's head section using a style element

Pros

Easy to implement for small projects, requires no additional HTTP requests to external files, and allows for centralized styling of one page.

cons

Not reusable across different pages; large amounts of internal CSS can make your HTML file cluttered and harder to maintain. For multi-page websites, External CSS
